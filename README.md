# MurderAI - AI 剧本杀

一个基于 AI 的沉浸式剧本杀游戏平台，玩家可以通过对话与多个 AI 角色互动，推进剧情，收集线索，最终揭开真相。

## 项目简介

MurderAI 是一个创新的 AI 剧本杀游戏，结合了传统剧本杀的推理乐趣与大语言模型的智能对话能力。玩家可以选择不同的剧本副本，扮演其中的角色，通过与其他 AI 角色的对话来推进剧情、收集线索，最终指认真凶。

### 核心特性

- **多副本支持**：支持多个独立的剧本副本，每个副本都有独特的故事背景和角色设定
- **角色选择**：玩家可以选择特定角色或随机抽取角色进入游戏
- **沉浸式对话**：基于 SSE 的流式对话，提供实时的沉浸式体验
- **结构化剧情**：通过阶段控制、线索系统和事件触发机制，保证剧情的连贯性和可玩性
- **智能推理**：AI 角色根据人设、记忆和目标做出符合逻辑的回应
- **结案系统**：玩家可以基于收集的线索进行最终指认，系统会判定推理结果并揭晓真相

### 技术架构

项目采用前后端分离架构：

**后端技术栈**
- Java 17
- Spring Boot 3.4.5
- Spring AI Alibaba (DashScope)
- SSE (Server-Sent Events) 流式响应
- 内存会话管理

**前端技术栈**
- React 18
- TypeScript
- Vite
- CSS 动画

### 当前状态

项目已完成 MVP 阶段，验证了以下核心功能：
- 多副本管理和选择
- 角色选择和随机抽取
- 基于 sessionId 的会话化游戏流程
- SSE 流式对话
- 结构化消息事件（系统消息、玩家消息、角色发言、旁白、线索等）
- 调查进度和线索展示
- 最终指认与真相揭晓

## 快速开始

### 环境要求

- JDK 17+
- Node.js 18+
- Maven 3.6+
- 阿里云 DashScope API Key

### 后端启动

1. 进入后端目录：
```bash
cd ai-murder-backend
```

2. 配置环境变量：
设置 `AI_DASHSCOPE_API_KEY` 环境变量为你的阿里云 DashScope API Key

3. 启动后端服务：
```bash
mvn spring-boot:run
```

后端服务将在 `http://localhost:8080` 启动

### 前端启动

1. 进入前端目录：
```bash
cd ai-murder-frontend
```

2. 安装依赖：
```bash
npm install
```

3. 启动开发服务器：
```bash
npm run dev
```

前端服务将在 `http://localhost:5173` 启动

### 使用说明

1. 打开浏览器访问 `http://localhost:5173`
2. 在首页选择一个剧本副本
3. 选择一个角色或随机抽取
4. 开始游戏，通过对话与 AI 角色互动
5. 收集线索，推进剧情
6. 在适当时机进行最终指认
7. 查看真相揭晓

## 主要接口

### 后端接口

- `POST /api/game-sessions` - 创建游戏会话
- `GET /api/scripts` - 获取剧本列表
- `GET /api/scripts/{scriptId}/characters` - 获取剧本角色列表
- `POST /api/chat/stream` - SSE 流式对话接口
- `POST /api/game-sessions/{sessionId}/accuse` - 最终指认

详细接口说明请参考 `ai-murder-backend/README.md`
